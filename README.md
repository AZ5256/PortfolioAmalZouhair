# Mehdi Drira — Portfolio

Portfolio personnel de Mehdi Drira, développeur iOS.

## Technologies

- HTML
- CSS
- JavaScript
- GitHub Pages

## Installation

Aucune dépendance. Ouvrir `index.html` dans un navigateur.

## GitHub Pages

Dans GitHub :
`Settings` → `Pages` → `Deploy from a branch` → `main` → `/ (root)`.

## À personnaliser

Dans `index.html`, remplacer :
- `TON_EMAIL@example.com`
- le lien GitHub
- le lien LinkedIn
- les informations d'expérience/projets si nécessaire
- éventuellement ajouter `assets/profile.jpg` et l'utiliser comme photo de profil.
